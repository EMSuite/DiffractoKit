# Test fixtures

One row per committed fixture file under `Tests/*/Fixtures/`: size, the script under `tools/` that names it (the generator or its
pin script; a few scripts write a whole directory; a script found only by file-name prefix, tool-folder name or test module is marked so), and a note where the origin is not the kit's own pinned reference (every CIF says its source). 176 files.

Licence: the sources and licences are in the next two sections and in `NOTICE`. The pin JSON files are computed by the scripts under `tools/pins/` and ship under the kit's GPL-3.0-only licence. The CIFs were not generated by those scripts: 16 come from the tests of mac4DSTEM 7448401b (GPL-3.0, same author) and 20 were written for this kit (GPL-3.0-only); the pin scripts only read them. The 28 under `cif-export/written/` are the kit's own `CIFExport` output, committed so pymatgen's reading of them can be pinned. The 66 rows marked *third party* keep their own licence. No fixture is a copy of a real dataset (`index-real-nanowire.json` holds spot lists derived from a public dataset, not its patterns): the committed text fixtures carry no local path or personal name (checked by search), and real datasets are read from `$MACEM_DATA` and never copied into the repo.
